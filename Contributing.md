# Contribution Guidelines

Thank you for considering contributing to **Awesome PDF Tools**!

## How to contribute

1. **Fork** this repository
2. **Edit** the `README.md` file
3. **Add your entry** in the most appropriate section
4. **Submit** a pull request

## Guidelines

- Make sure the tool or resource is genuinely useful
- Keep descriptions short, clear and objective (max 1-2 sentences)
- Add entries in alphabetical order within each section
- Use the following format:
  ```
  - [Tool Name](https://url.com) - Short description of what it does.
  ```
- Do not add tools that are paid-only without a free tier
- Do not add duplicate entries

## Quality standards

- The tool must be actively maintained
- The website/repo must be accessible
- No spam, affiliate links, or self-promotion without genuine value

Thank you for helping make this list better! 🙌
